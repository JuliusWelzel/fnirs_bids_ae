# fNIRS BIDS AE

A Python script for processing fNIRS data into BIDS format with artifact estimation.

## Installation

This project uses [uv](https://github.com/astral-sh/uv) for dependency management.

Install dependencies:
```bash
uv sync
```

## Description

This script processes functional near-infrared spectroscopy (fNIRS) data and converts it to the Brain Imaging Data Structure (BIDS) format.
